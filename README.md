# 🎓 서원대 모아보기 · CLI

서원대학교 e-campus, 확정 수강 시간표, 통합정보시스템 ERP를 **한 대의 터미널**에서 보는 비공식 학생 CLI입니다.  
학교 연동은 `lib/back` 에 있고, 화면은 `lib/front/tui` 입니다. 웹 서버를 띄우지 않습니다. 이 프로세스가 학교 서버에 직접 접속합니다.

현재 버전은 `v1.0.0` 입니다.

> 서원대학교 공식 SDK가 아닙니다. 계정·세션·다운로드 파일은 공개 저장소에 올리지 마세요.

**`Node.js 22+` · `TypeScript` · `키보드 TUI` · `학교 서버 직접 연동`**

[실행 장면](#demo) · [핵심 기능](#features) · [키보드 조작](#terminal) · [실행 방법](#usage) · [문서](#docs)

## 공개 자료와 보안

실제 계정의 이름·학번·학과·성적·수강 정보가 포함된 실행 녹화를 공개 자료에서 제거했습니다. 공개 예시는 가상 데이터만 사용합니다. 2026-10-10에 저장소를 재생성해 현재 보안 수정된 코드로 새 main 이력을 시작했습니다. 이전 main·gui·tui 이력은 새 저장소에 업로드하지 않았습니다. 현재 파일·이력 검사 후보는 0건이며, 기존 사용자는 [새 복제본 이전 안내](./docs/history-cleanup.md)를 따릅니다.

2026-10-10 보안 점검에서 API 통신 범위, 인증 상태, 로그, 터미널 제어 문자, 파일 저장과 시간표 출력을 보강했습니다. 발견 항목과 CWE, 검증 결과, 남은 조치는 [보안 감사 보고서](./docs/security-audit.md)에 있습니다.

## 프로젝트 위치

이 저장소는 [seowon-client-web](https://github.com/hy040504/seowon-client-web)을 개발하고 확장하기 전에 학교 연동과 기능 흐름을 검증하는 **MVP 성격의 터미널 클라이언트**입니다. 먼저 CLI에서 실제 e-campus·시간표·ERP 응답과 예외 상황을 확인한 뒤, 여러 학생이 브라우저에서 사용하는 웹 기능으로 확장합니다.

- `seowon-cli`: 단일 사용자·터미널 중심의 연동 검증, 기능 실험, 문제 사례 기록
- `seowon-client-web`: 검증된 기능을 여러 사용자와 웹 화면에 맞게 확장하는 제품 저장소
- 이 저장소의 CLI 화면이나 내부 호출 구조가 웹 프로젝트의 최종 UI·API 구조를 그대로 의미하지는 않습니다.

## 🧠 현재 구성

호스트와 쿠키는 서비스마다 다릅니다. 하나를 다른 자리에 넣지 않습니다.

| 구성 요소 | 위치 | 담당 역할 |
| :--- | :--- | :--- |
| e-campus LMS | `ecampus.seowon.ac.kr` · `EcampusClient` | 로그인, 과제·공지·자료·이러닝, 이번 학기 성적 |
| 확정 수강 시간표 | `sugangh.seowon.ac.kr` · `CourseRegistrationClient` | 확정 수강 목록으로 시간표 |
| 통합정보 ERP | `info.seowon.ac.kr` · `ErpClient` | 지난 학기 성적. 이번 학기 LMS 성적과 다름 |
| 조회 묶음 | `lib/back/campus.ts` | 로그인 세션 하나에서 메뉴가 부르는 함수 |
| 터미널 화면 | `lib/front/tui` | 메뉴, 표, 저장 폴더 선택 |

> **ERP ≠ e-campus 성적.** 지난 학기는 `info.seowon.ac.kr`, 이번 학기 강의실 성적은 `ecampus.seowon.ac.kr` 입니다.

## 🔁 요청이 지나가는 구조

```text
터미널
  학번 · 비밀번호
        │
        ▼
  lib/front/tui/cli.ts
        │
        ▼
  lib/back/campus.ts          메모리 세션 하나
        ├─ client.cookieJar      ecampus
        ├─ courseReg.cookieJar   시간표
        └─ erp.cookieJar         지난 성적
```

수동 입력한 학번·비밀번호·학교 쿠키를 CLI가 디스크에 저장하지 않습니다. 자동 로그인에 쓰는 `.env`는 사용자가 관리하는 민감한 파일입니다. 프로세스 종료 시 메모리의 세션 참조가 사라져도 학교 세션이 서버에서 폐기된다는 뜻은 아닙니다. 테마 설정은 `data/tui-config.json` 에 남습니다.

추적 로그는 `fetchAcademicOverview()` 처럼 **부른 함수 이름과 소요 시간**이고, 그 아래에는 `lib/back` 기준 service · engine 파일을 적습니다. 호출 인자·학번·비밀번호·쿠키·서버 원문·저장 경로를 추적 로그에 남기지 않습니다. 조회 화면에서 본인이 선택한 성적·수강 정보는 계속 표시하므로 그 화면을 공개 녹화하지 마세요.

## ✨ 핵심 기능

| 기능 | 설명 |
| :--- | :--- |
| 🔑 로그인 | 학번 입력 또는 `.env` 의 `SEOWON_SID` · `SEOWON_PW` |
| 🔥 지금 할 것 | 지금 제출 기간의 미제출 과제와, 지금 학습 기간의 미학습 차시 |
| 📝 과제 | 전체 · 지금 할 수 있는 과제 · 미제출 · 제출한 과제. 제출과 파일 삭제 |
| 📢 공지 · 📁 자료 | 과목별 본문과 첨부. 저장 위치를 고른 뒤 받는다 |
| 💻 이러닝 | 전체 조회는 기간이 지난 차시도 포함. 수강하기는 이캠퍼스 메인. 학습률은 과목별 진도 방식과 대체 방식을 사용해 이력 중 가장 높은 값을 읽음 |
| 🗓️ 시간표 | 과목과 시간. PNG 저장은 과목 선택과 별도 메뉴 |
| 📊 성적 | 이번 학기는 e-campus, 지난 학기는 ERP 등급·평점 |
| 📌 전체 현황 | 기간과 관계없는 미제출 과제, 기간 안 미완료 차시. 0이 아니면 밝은 빨강 |
| ⚙️ 설정 | 테마 색, 메뉴를 바꿀 때 화면 지우기, 캐시 비우기 |
| 📚 문서 정리 (Dev) | README·docs 색인·버그 수정 기록 위치를 확인 |
| 🧪 함수 전수 조사 (Dev) | 개발용 함수 점검. 과제 제출과 로그아웃은 건너뜀 |

파일을 받을 때는 매번 폴더를 고릅니다. 그 폴더에서 `s` 를 누르면 저장하고, Esc 는 취소입니다. 첨부·영상·시간표 PNG 는 받는 동안 한 줄 진행 막대가 100%까지 찬 뒤 지워지고, 그 다음에 저장 결과가 나옵니다.

## 🧭 로그인부터 조회까지

학번 로그인 또는 `.env` 로그인이 끝나면 세션은 이 프로세스 메모리에만 남고, 아래 메뉴를 같은 세션으로 오갑니다. `2`~`9`, `C`, `T` 는 로그인이 있어야 열립니다. `1` 로그인, `I` 프로그램 정보, `0` 종료는 로그인 전에도 있습니다.

```mermaid
flowchart TD
  login["1. 학번 로그인 또는 .env 로그인"] --> mem["2. 이 프로세스 메모리에만 학교 쿠키"]
  mem --> menu["3. 사이드바에서 메뉴를 고른다"]
  menu --> lms["e-campus<br/>지금 할 것 · 과제 · 공지 · 자료 · 이러닝 · 이번 성적 · 전체 현황"]
  menu --> tt["시간표<br/>과목 목록 또는 PNG 저장"]
  menu --> erp["ERP<br/>지난 성적"]
  lms --> stay["4. 같은 세션으로 다음 메뉴"]
  tt --> stay
  erp --> stay
  stay --> close["5. 0 종료"]
  close --> gone["메모리 세션 삭제"]
```

```mermaid
  cfg["C 설정"] --> cache["캐시 비우고 다시 조회"]
  cfg --> bye["로그아웃"]
  cfg --> theme["TUI 테마 색"]
  cfg --> clear["메뉴 전환 시 화면 지우기"]
```

파일을 받는 자리(참고첨부, 제출파일, 공지·자료 첨부, 영상, 시간표 PNG)는 모두 폴더를 고릅니다. 그 폴더에서 `s` 가 저장, Esc 가 취소입니다.

## 🖥️ 터미널 화면

키보드만 씁니다. 마우스로 메뉴를 고르지 않습니다.

| 조작 | 동작 |
| :--- | :--- |
| 숫자 · 단축키 | 사이드바 이동 |
| ↑↓ Enter | 목록에서 고르기 |
| `/` | 목록 검색 |
| Esc | 이전 화면. 메인에서 Esc 면 종료 |
| `q` | 종료 |
| 비밀번호 | 학번 로그인에서 입력 중 `*`, Enter 뒤 `입력완료` |
| 저장 | 폴더를 고른 뒤 `s` |

선택 줄은 배경을 끝까지 깔지 않습니다. 목록 칸은 그대로 그리고, 고른 줄의 글자만 테마 색으로 바꿉니다.

이러닝 **전체 조회**와 **학습률**은 같은 차시 범위이고, 지금 수강 기간이 아닌 차시도 포함합니다. 전체 조회는 수강하기·영상 받기이고, 학습률만 퍼센트를 묻습니다. 학습률은 그 과목 이러닝 목록의 학생 번호와 진도 방식으로 이력을 읽고, 표에 있는 값 중 가장 높은 퍼센트입니다. 목록 폼이나 특정 진도 방식이 실패해도 표준 진도 방식을 순서대로 재시도합니다. 이력이 없을 때만 0%입니다. **들을 차시**만 지금 학습 기간의 미학습·학습중입니다.

출결이 비어 있거나 이미 다 들은 경우에는 `차시 N건을 전부 수강하였습니다.`처럼 그 상황을 보여 줍니다. 수강하기는 브라우저에서 이캠퍼스 메인(`https://ecampus.seowon.ac.kr/home/mainHome/Form/main`)만 엽니다. 이 프로그램의 쿠키를 브라우저에 넣지 않습니다.

시간표 **과목 목록**은 시간만 보여 줍니다. **PNG 저장**을 따로 고르면 폴더를 지정해 그림을 받습니다. SVG·HTML 파일은 만들지 않습니다.

프로그램 정보는 TypeScript, Node.js 22, 자체 터미널 메뉴, axios, cheerio 를 적습니다. 화면용 웹 프레임워크는 쓰지 않습니다.

### 🎨 테마 미리보기와 저장

`C 설정` → `3 TUI 테마 색`에서 테마를 미리 보고 저장합니다. 목록의 선택 글자와 표의 강조색을 취향에 맞게 바꿀 수 있습니다.

테마 22종을 미리 보고 취소하거나 선택한 테마를 저장할 수 있습니다.

## ▶️ 실행 방법

필요 환경은 Node.js 22 이상입니다. `seowon-client-web` 을 띄울 필요가 없습니다.

### 1. Windows에서 바로 켜기

```bat
cli.bat
```

`node_modules` 가 없으면 잠금 파일 기준으로 `npm ci` 한 뒤 메뉴를 엽니다. 설치가 실패하면 메뉴를 실행하지 않고 실패 종료 코드를 반환합니다.

`cli.bat`은 UTF-8 코드 페이지를 설정하고 Windows 줄바꿈(CRLF)을 사용합니다. Git에서 받아도 같은 줄바꿈을 유지하도록 `.gitattributes`에 지정했습니다. 주석이 명령어로 실행되던 오류의 원인과 검증은 [CASE-021](./docs/cases/사례-21-Windows-배치-실행-오류.md)에 기록했습니다.

```bat
cli.bat --help
rem .env에 로그인 값을 설정한 뒤 실행
cli.bat --suite all
```

### 2. npm

```powershell
npm install
npm run api-cli
```

| 명령 | 하는 일 |
| :--- | :--- |
| `npm run api-cli` | `tsx` 로 `lib/front/tui/cli.ts` 실행 |
| `npm run dev` | 같은 진입점 |
| `npm run typecheck` | 타입만 검사 |
| `npm run build` | 검증된 `dist` 정리 후 `tsc` 및 로그인 암호화 파일 복사 |
| `npm start` | `node dist/front/tui/cli.js` |

대화형 메뉴는 TTY 가 필요합니다. 조사가 끝나면 프로세스가 종료됩니다.

## 2026-10-10 보안 보강

- API는 서비스별 승인된 HTTPS origin만 사용하고 리다이렉트도 같은 origin으로 제한합니다. 영상은 로그인 쿠키·인증 헤더를 전달하지 않는 별도 클라이언트로 받습니다.
- OTP 미완료 응답을 로그인 성공으로 취급하지 않고, 새 인증 전에 이전 계정 상태를 비웁니다. 객체 직렬화와 오류에서 인증정보·학생 데이터를 숨깁니다.
- 추적 인자와 verbose 원문을 제거하고, 외부 문자열의 터미널 제어 문자를 차단합니다. NO_COLOR에서도 비밀번호 마스킹을 유지하며 마스킹 불가 환경에서는 입력을 거부합니다.
- 파일명과 업로드 대상, 저장 경로를 검증하고 완성된 파일을 원자적으로 저장합니다. 새 파일·디렉터리의 POSIX 권한은 0600·0700이며 Windows에서는 디렉터리 ACL이 적용됩니다.
- 공개 녹화 11개와 실제 과제 PNG를 공개 자료에서 제거하고 현재 공개 파일 검사와 Windows·Ubuntu CI를 추가했습니다. 과거 이력의 실제 식별 정보·소속과 개인 미디어·응답도 제거했습니다.
- [보안 안내](./SECURITY.md) · [CWE와 검증 결과](./docs/security-audit.md)
- 빌드 전 `dist`를 안전하게 정리해 삭제된 소스의 구버전 실행 파일이 다시 배포되지 않게 합니다. 사용 중인 cookiejar 연동 의존성의 최소 요구에 맞춰 Node.js 22 이상으로 실행합니다.

## 2026-10-10 이력 정리와 공개 보호

- 모든 브랜치의 README·C·Python 예시에서 실제 이름·학번·소속을 가상 값으로 바꾸고 개인 미디어·응답 파일을 과거 이력에서도 제거했습니다.

- 이전 저장소에서 Windows·Ubuntu의 전체 검사·90개 테스트·빌드·감사를 통과한 코드를 사용합니다. 새 저장소의 검증은 [GitHub Actions](https://github.com/hy040504/seowon-cli/actions)에서 실행합니다. 이전 주소의 접근 여부와 서버 영구 삭제는 구분해 기록합니다.

## 최근 반영 사항

- 공지 상세에서 제목과 공유 메뉴가 본문에 섞이던 문제를 수정했습니다. 실제 본문 영역을 읽고, 짧거나 빈 본문과 중첩된 HTML을 올바르게 처리합니다. ([CASE-022](./docs/cases/사례-22-공지-본문-추출.md))
- `cli.bat`의 한글 주석이 명령어처럼 실행되던 Windows 실행 오류를 수정했습니다. UTF-8 코드 페이지와 CRLF 줄바꿈을 적용하고, 의존성 설치 실패 시 종료 코드를 반환하도록 정리했습니다. ([CASE-021](./docs/cases/사례-21-Windows-배치-실행-오류.md))
- 로그인 메뉴 `1 학번 로그인` 의 비밀번호 입력을 `*` 로 가립니다. Enter 뒤에는 같은 줄이 `입력완료` 로 바뀌어 비밀번호가 화면에 남지 않습니다. ([CASE-020](./docs/cases/사례-20-비밀번호-입력-마스킹.md))
- `외부저장소-강제최신화.bat` 를 추가했습니다. 원격 `origin/main` 을 로컬에 강제 동기화합니다. 의존성 설치·빌드는 수행하지 않으며, 정상 이력일 때만 백업 브랜치를 생성합니다. 공통 이력이나 이력 검사에 문제가 있으면 강제 reset 전에 중단합니다.
- 개발 도구 메뉴에 `문서 정리 (Dev)`를 추가해 README·docs 색인·버그 수정 기록 위치를 CLI에서 확인할 수 있습니다.
- 과목별 과제·이러닝 조회를 병렬화하고, 제출파일 스냅샷 갱신 인덱스를 재사용하도록 내부 조회 흐름을 최적화했습니다.
- 공통 동시성 제한 함수에 잘못된 제한값 보정과 관련 주석을 추가했습니다.
- `학습률 · 차시마다 퍼센트 조회`는 퍼센트 필드가 없는 e-campus 응답도 `학습 인정 시간 ÷ 차시 길이`로 계산합니다.
- 빈 학습 이력 응답을 즉시 `0%`로 확정하지 않고 대체 조회를 계속합니다.
- 개발용 메뉴는 `함수 전수 조사 (Dev)`로 표시하며, 문서 정리는 `docs/README.md`와 `docs/BUGFIX_LOG.md`에서 관리합니다.
- 실제 `.env` 로그인 세션으로 학습률 조회 차시를 검증했습니다.
