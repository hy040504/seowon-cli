# 버그 수정 로그

## 2026-10-10 저장소 재생성

- 사용자의 요청으로 같은 이름의 공개 저장소를 새로 만들고 현재 TypeScript 코드로 main 이력을 시작합니다. 이전 main·gui·tui Git 이력은 새 저장소에 포함하지 않습니다.
- 기존 코드·이력·설정은 로컬 비공개 백업으로 보관하고, 공개 소스와 개인 실행 데이터는 분리합니다.
- 이전 CI 기록은 승계되지 않으므로 새 저장소에서 전체 검증을 다시 실행합니다. 이전 커밋·녹화 주소의 공개 접근과 서버 영구 삭제는 구분해 기록합니다.

## 2026-10-10 전체 이력 정리와 공개 보호

- 격리 복제본에서 전체 브랜치·로컬 백업 참조의 실제 이름·학번·소속과 개인 미디어·학생 응답을 정리했습니다. 현재 파일·이력 검사 모두 0건입니다.
- 원본은 무시되는 로컬 비공개 Git bundle·메타데이터 ZIP으로 보존하고, 작업 저장소의 이전 reflog·불필요한 객체를 정리했습니다.
- 검토된 가상 미디어는 경로와 SHA-256이 정확히 일치할 때만 허용하고 이전 미검토 버전·다른 경로의 복사본을 차단하는 회귀 테스트를 추가했습니다. 전체 테스트는 90개입니다.
- CI에 전체 이력 검사를 추가하고 비공개 취약점 제보를 활성화했습니다. 강제 최신화 도구는 공통 이력·이력 검사를 통과해야 백업·reset을 수행합니다.
- [이력 정리 결과와 기존 복제본 이전](./history-cleanup.md)에 원격·외부 캐시의 한계도 기록했습니다.
- Windows CI의 임시 경로가 8.3 별칭을 사용할 때 정상 `dist`를 외부 경로로 오판하던 빌드 정리 검사를 수정했습니다. 실제 프로젝트 루트와 `dist`를 모두 해석해 비교하고 확인된 경로만 정리합니다. 링크 출력 디렉터리 차단은 유지합니다.

## 2026-10-10 공개 전 보안 감사와 개인정보 정리

- 복사된 API 엔진에 서비스별 HTTPS·리다이렉트 제한, 인증·OTP 상태 정리, 안전한 오류와 직렬화, 영상 인증정보 분리, 암호학적 난수를 적용했습니다.
- 호출 인자·verbose 원문·학교 응답 로그를 제거하고 터미널 제어 시퀀스, 파일명·업로드·파일 저장과 시간표 SVG·HTML을 보강했습니다.
- 비밀번호·학번 명령행 옵션을 제거했습니다. NO_COLOR와 마스킹 동작을 분리하고 마스킹 불가 입력을 거부합니다.
- 공개 녹화 GIF 11개와 실제 과제 PNG 1개를 공개 자료에서 제거했습니다. 이전 문서의 실행 자료 개수와 링크는 이 날짜부터 가상 예시 중심으로 변경했습니다.
- 현재 공개 파일 및 Git 이력 검사, 배포 파일 허용 목록, Windows·Ubuntu 검증 워크플로를 추가했습니다. 수정 항목·CWE·검증·남은 조치는 [보안 감사 보고서](./security-audit.md)에 있습니다.
- 서비스 계층에서도 OTP 리다이렉트를 로그인 완료로 받지 않도록 수정하고, 로그아웃·시간 초과 뒤 늦은 로그인 반영을 검증했습니다.
- 빌드 전에 검증된 `dist`만 정리해 삭제된 소스의 구버전 실행 파일이 재배포되지 않게 했습니다. 링크로 연결된 출력 폴더는 정리하지 않습니다.
- 설치된 cookiejar 연동 의존성의 요구 버전에 맞춰 Node.js 22 이상으로 문서·패키지를 맞췄습니다.

## 2026-10-09 공지 상세 본문 추출 수정

- 현재 e-campus의 `#atclCtsText.content-field`를 인식하지 못해 제목·작성자·공유 메뉴까지 본문으로 표시하던 문제를 수정했습니다. ([CASE-022](./cases/사례-22-공지-본문-추출.md))
- Cheerio로 본문 요소를 선택해 중첩된 `div` 뒤의 내용까지 읽고, 구버전 본문 영역과 내용 라벨도 지원합니다.
- 짧거나 빈 본문을 그대로 유지하며, 본문 영역을 찾지 못하면 화면 전체 텍스트로 대체하지 않습니다.
- `npm test`에 공지 파서·상세 서비스 회귀 테스트 7개를 추가했습니다.
- `npm run typecheck`, `npm run build`를 통과했습니다.
- 실제 e-campus 공지 6건의 본문이 서버의 본문 영역과 일치하고, 첨부가 있는 공지의 첨부 1건도 정상 조회되는 것을 확인했습니다.

## 2026-10-08 Windows 배치 실행 오류 수정

- `cli.bat` 실행 시 한글 주석 일부가 명령어로 해석되고 npm 사용법만 출력되던 오류를 수정했습니다. ([CASE-021](./cases/사례-21-Windows-배치-실행-오류.md))
- 한글 주석을 읽기 전에 `chcp 65001`로 UTF-8 코드 페이지를 설정하고, 배치 파일을 CRLF 줄바꿈으로 저장했습니다.
- `.gitattributes`에 `cli.bat text eol=crlf`를 추가해 Git 체크아웃에서도 줄바꿈을 유지합니다.
- 의존성 설치를 별도 명령으로 실행해 실패 종료 코드를 전달하고, 프로젝트 폴더 이동 실패 시에도 종료합니다.
- 실제 터미널에서 메뉴 표시와 `0`번 정상 종료를 확인했습니다. `--help`는 종료 코드 0, `--suite invalid`는 종료 코드 1을 반환했습니다.
- 프로젝트 README의 Windows 실행 설명, docs 사례 색인과 수정 로그를 갱신했습니다.

- [문서 색인](./README.md)에 문서 구성과 기능별 촬영 자료 표를 추가하고, 관련 문제 사례를 연결했습니다.

- 시간표 PNG 예시는 가상 데이터로 별도 생성한 결과임을 캡션과 문서에 표시했습니다.
- 데스크톱·모바일 렌더링, 이미지와 펼쳐보기, 원본 링크를 검수했습니다. 복사한 자료의 SHA-256도 원본과 일치했습니다.
