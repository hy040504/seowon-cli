# CASE-007: 전체 조회에서 차시를 고르면 바로 학습률 오류

## 증상

- 차시 목록에서 한 줄을 누르면 "학습률을 읽지 못했습니다" 가 나오고, 동작은 영상 다운로드와 뒤로뿐이었다.
- 전체 조회와 학습률이 뭐가 다른지 구분이 안 됐다.

## 원인

- 목록에서 고르는 즉시 `fetchProgress` 를 호출했다.
- 두 메뉴가 같은 차시를 다른 목적으로 쓰는데 화면이 그 차이를 말하지 않았다.

## 해결

- 메뉴 이름을 전체 조회로 바꿨다. 여기서 고르면 학습률을 묻지 않는다.
- 동작은 수강하기, 영상 다운로드, 뒤로이다.
- 학습률 메뉴만 같은 차시 전부에 퍼센트를 묻는다. 학습률은 동시에 최대 5건까지 조회한다.
- 들을 차시만 지금 학습 기간의 미학습·학습중으로 좁힌다.
