# CASE-009: 전체 현황이 해결과제이고 미완 숫자가 색으로 안 보임

## 증상

- 전체 현황 열이 "해결과제" 이고, 기간이 지난 미제출은 빠진다.
- 0이 아닌 건수도 회색이거나, 줄을 고르면 빨강이 사라진다.

## 원인

- 건수가 `dueNow` 기준이었다.
- 선택 줄 전체를 반전 영상으로 칠하면 칸에 입힌 색이 같이 뒤집힌다.

## 해결

- 열 이름은 미제출 과제, 미완료 차시다.
- 미제출은 기간과 무관하게 센다. 미완료 차시는 지금 학습 기간 안만 센다.
- 0은 회색, 1 이상은 밝은 빨강이다.
- 선택 줄은 번호만 반전하지 않고, 배경을 깔아 칸 색을 남긴다. 배경이 줄 끝까지 가는 내용은 [CASE-012](./사례-12-선택-줄-배경.md) 이다.

## 적용 파일

- `lib/front/tui/tui-kit.ts` — `tableSelect`, `rowBar`
