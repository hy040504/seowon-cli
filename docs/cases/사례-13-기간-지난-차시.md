# CASE-013: 전체 조회가 지금 수강 기간인 차시만 보여 줌

## 증상

- 이러닝 전체 조회에 기간이 지난 차시가 없다.
- 들을 차시와 달리 전체 조회는 지난 주차도 보여야 한다.

## 원인

- 차시 목록 요청의 `listScale` 이 10이라 앞부분에서 끊겼다.
- 열린 주차의 카드만 파싱하고, 제목만 있는 지난 주차는 버렸다.

## 해결

- 한 페이지를 100건으로 두고, 100건이 차면 다음 페이지를 이어 받는다.
- 차시가 비어 있는 주차는 그 주차 id 로 한 번 더 조회한다.
- 학교가 주차 id 를 무시하고 같은 전체 목록을 다시 주면, 남은 주차 요청은 멈춘다.
- 기간이 지났지만 아직 미학습인 차시는 "기간 외" 로 표시한다. 완료로 치지 않는다.
- 들을 차시는 그대로 지금 기간의 미학습·학습중만 보여 준다.

## 적용 파일

- `lib/back/engine/ecampus/login.ts` — `getElearningLessonList`, `collectLessonListHtml`
- `lib/back/engine/ecampus/elearning.ts` — 차시 HTML 파서
- `lib/front/tui/cli.ts` — `lessonRowStatus`
