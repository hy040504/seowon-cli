# CASE-017: 한 진도 방식 오류로 학습률 전체 조회가 중단됨

## 증상

- 이러닝의 `학습률 · 차시마다 퍼센트 조회`에서 여러 차시가 모두 실패한다.
- 특정 과목에서만 학습률을 읽지 못하거나, 첫 번째 요청 오류 뒤 다음 차시로 넘어가지 않는다.

## 원인

- 과목별 진도 방식이 다르지만 첫 번째 방식의 HTTP 오류가 전체 조회 예외로 전파됐다.
- 목록 폼이 로그인 화면이나 빈 응답을 반환하면 학생 번호와 진도 방식 확보 단계에서 즉시 중단됐다.
- 학습 이력 요청의 `listScale`이 10이라 오래된 이력이 많은 차시의 값을 충분히 읽지 못할 수 있었다.

## 해결

- 목록 폼 조회 실패 시에도 기본 학생 번호와 표준 진도 방식으로 조회를 계속한다.
- 진도 방식별 요청을 개별적으로 처리하고 오류가 나면 `STUDY_TOTAL_TM`, `WEEK`, `PAGE`를 순서대로 재시도한다.
- 학습 이력 요청의 조회 건수를 100건으로 늘리고 HTML·JSON 응답을 모두 허용한다.
- 응답에서 확인되는 가장 높은 학습률을 사용하며, 이력이 없을 때만 0%로 표시한다.

## 적용 파일

- `lib/back/services/ecampus/elearning.ts` — 폼·진도 방식 폴백과 이력 조회
- `lib/front/tui/cli.ts` — 개발용 함수 전수 조사 메뉴 표기
- `README.md`, `docs/` — 기능 및 버그 기록 정리
