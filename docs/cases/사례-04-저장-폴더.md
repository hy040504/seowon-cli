# CASE-004: 저장할 때마다 폴더를 묻지 않음

## 증상

- 자료·영상·시간표가 묻지 않고 정해진 폴더에 저장된다.

## 원인

- 저장 경로가 호출부에 고정되어 있었고, 폴더를 고르는 화면이 모든 저장에 연결되어 있지 않았다.

## 해결

- 저장마다 폴더 트리를 연다. Enter 는 폴더로 들어가고, `s` 는 현재 폴더에 저장하고, Esc 는 취소다.
- 마지막에 고른 폴더를 다음 저장의 시작 위치로 기억한다. 같은 이름이 있으면 덮어쓸지 확인한다.
- 터미널이 아니면 경로를 입력받는다.

## 적용 파일

- `lib/front/tui/tui-kit.ts` — `directoryTree`
- `lib/front/tui/tui-actions.ts` — `chooseSavePath`
