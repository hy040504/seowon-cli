# CASE-003: 다운로드 로그에 웹 경로와 블록 진행바가 남음

## 증상

- `POST /api/download` 다음에 `██░░░░` 같은 진행바가 붙는다.
- 대기 표시 `⠏` 가 결과 줄에 붙어서 `⠏ 이러닝 ← 200` 처럼 보인다.

## 원인

- 웹 클라이언트의 다운로드 진행 표시와 경로형 로그가 남아 있었다.
- 스피너가 다음 `console.log` 를 지우기 전에 다른 출력이 같은 줄에 이어졌다.

## 해결

- 로그에 웹 경로를 찍지 않는다. 함수 이름만 남긴다.
- 첨부, 이러닝 영상, 시간표 PNG 는 받는 동안 한 줄 진행 막대를 그린다. 100%까지 채운 뒤 그 줄을 지우고, 그 다음에 저장 결과를 낸다.
- 받기에 실패하면 100%로 채우지 않고 막대만 지운다. 막대 글자가 결과 줄에 붙지 않게 타이머를 먼저 멈춘다.
- 조회 대기 표시는 다른 출력이 쓰기 전에 자기 줄을 지운다. 학습률 결과 막대(`|████| 80%`)는 다운로드 막대와 별개다.

## 적용 파일

- `lib/front/tui/tui-kit.ts` — `withDownloadBar`
- `lib/front/tui/tui-actions.ts` — 첨부·영상·시간표 저장
- `lib/back/campus.ts` — 받은 바이트를 막대에 알림
- `lib/front/tui/cli.ts` — `spin`
