# CASE-003: 다운로드 로그에 웹 경로와 블록 진행바가 남음

## 증상

- `POST /api/download` 다음에 `██░░░░` 같은 진행바가 붙는다.
- 대기 표시 `⠏` 가 결과 줄에 붙어서 `⠏ 이러닝 ← 200` 처럼 보인다.

## 원인

- 웹 클라이언트의 다운로드 진행 표시와 경로형 로그가 남아 있었다.
- 스피너가 다음 `console.log` 를 지우기 전에 다른 출력이 같은 줄에 이어졌다.

## 해결

- 받는 동안은 대기 표시와 함수 추적만 남긴다. 블록 진행바는 그리지 않는다.
- 학습률 퍼센트 막대(`|████| 80%`)는 결과 표시라 그대로 둔다.
- 스피너는 다른 출력이 쓰기 전에 자기 줄을 지운다.

## 적용 파일

- `lib/front/tui/cli.ts` — `spin`
- `lib/back/campus.ts` — 다운로드 진행 콜백 제거
