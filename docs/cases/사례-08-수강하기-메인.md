# CASE-008: 수강하기가 차시 창으로 열려 이캠퍼스 메인이 아님

## 증상

- 수강하기가 임시 HTML로 차시 창에 POST 하고, 사용자는 이캠퍼스 메인으로 들어가길 원한다.
- CLI에 로그인돼 있어도 브라우저에는 그 쿠키가 없다.

## 원인

- 강의 창 주소로 숨은 폼을 제출하도록 만들어 두었다.
- 브라우저와 CLI는 쿠키를 공유하지 않는다.

## 해결

- 수강하기는 `https://ecampus.seowon.ac.kr/home/mainHome/Form/main` 만 연다.
- 임시 HTML과 차시 POST는 쓰지 않는다.
- 브라우저에 학교 로그인이 되어 있어야 메인으로 들어간다.

## 적용 파일

- `lib/front/tui/cli.ts` — `openCampusMain`
