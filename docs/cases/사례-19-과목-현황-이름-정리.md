# CASE-019: 과목별 종합 현황에 `Snapshot` 이름을 사용

## 증상

- `Snapshot`·`fetchSnapshot()`이 백업이나 과거 시점 복원용 데이터처럼 보인다.
- 실제로는 전 과목의 과제·이러닝 조회 결과를 세션 메모리에 캐시한다.

## 원인

- 기존 웹 API의 `/api/snapshot` 명칭을 서비스 함수·타입·CLI가 이어받았다.
- 현황 객체는 조회 시각을 포함하지만 영구 보존하거나 복원하는 기능은 없다.

## 해결

- 현황 타입과 서비스 함수를 `AcademicOverview`·`fetchAcademicOverview()`로 변경했다.
- 세션 캐시와 CLI 표시·조사 로그도 새 이름을 사용한다.
- e-campus 학습 기록 요청을 정규화하는 별도 `EcampusStudyRecordSnapshot`은 변경하지 않았다.

## 적용 파일

- `lib/back/types/academic-overview.ts`
- `lib/back/services/ecampus/classroom.ts`
- `lib/back/campus.ts`
- `lib/back/filters.ts`
- `lib/back/types/session.ts`
- `lib/front/tui/cli.ts`
- `lib/front/tui/tui-kit.ts`
