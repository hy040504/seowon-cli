# CASE-016: 학습률 조회가 실패로만 나옴

## 증상

- 이러닝 학습률이 차시마다 실패이고, 퍼센트가 안 나온다.
- 완료한 차시도 0%가 아니라 실패 문구다.

## 원인

- 진도 방식을 `STUDY_TOTAL_TM` 으로 고정했다. 과목은 `WEEK` 나 `PAGE` 인 경우가 있다.
- 학생 번호를 학번을 이어 붙여 만들었다. 강의실 화면의 `stdNo` 와 다르면 이력 표가 오지 않는다.
- 응답을 JSON으로 먼저 달라고 해서, 화면이 쓰는 HTML 표 대신 다른 본문이 왔다.
- 본문에 로그인 주소만 있어도 퍼센트를 보기 전에 실패로 버렸다.

## 해결

- 해당 과목 이러닝 목록에서 학생 번호와 진도 방식을 읽어 그 값으로 이력을 조회한다.
- 퍼센트가 없으면 `STUDY_TOTAL_TM`, `WEEK`, `PAGE` 를 이어서 본다. 과목 방식으로 0보다 큰 값이 나오면 거기서 멈춘다.
- 표 칸의 `100%` 를 읽고, 이력이 없다는 문구일 때만 0이다.
- 시청 기록은 보내지 않는다.

## 적용 파일

- `lib/back/engine/ecampus/login.ts` — `readLessonFormFields`
- `lib/back/services/ecampus/elearning.ts` — `fetchProgress`
- `lib/back/filters.ts` — `findProgressPercent`
