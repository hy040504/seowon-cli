# CASE-018: 학습 인정 시간만 반환되는 학습률 조회

## 증상

- 실제 로그인과 `viewLessonStudyDetail` 요청은 성공한다.
- 응답에 `prgrRatio` 같은 퍼센트 필드가 없고 `학습 인정 시간` 표만 반환된다.
- 빈 POST 결과를 학습률 `0%`로 오인하면 뒤의 GET 대체 조회까지 실행되지 않는다.

## 원인

e-campus 응답은 차시별 학습 기록을 `56분 30초`, `26분 21초`처럼 여러 행으로 반환한다. 학습률은 다음 계산으로 얻을 수 있다.

```text
학습률 = 총 학습 인정 시간 ÷ 차시 영상 길이 × 100
```

## 해결

- 목록의 차시 영상 길이를 초 단위로 보존한다.
- 학습 이력 표의 시간 열을 모두 합산한다.
- 빈 응답의 `0%`는 확정하지 않고 GET 대체 조회를 계속한다.
- 퍼센트 필드가 있는 서버 버전은 기존 파서를 우선 사용한다.

## 적용 파일

- `lib/back/services/ecampus/elearning.ts`
- `lib/back/services/ecampus/classroom.ts`
- `lib/back/types/snapshot.ts`
- `lib/back/campus.ts`

## 실제 검증

- 실제 `.env` 계정으로 e-campus 로그인
- 문제 차시 2건 직접 조회
- 각각 `100%` 계산 확인

상태: ✅ 해결
