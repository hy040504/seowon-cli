# CASE-020: 학번 로그인에서 비밀번호가 그대로 보임

## 증상

- 로그인 메뉴 `1 학번 로그인` 에서 비밀번호를 치면 글자가 화면에 그대로 찍힌다.
- README 의 터미널 화면 표는 `비밀번호 | 입력 중 *` 라고 적혀 있어 문서와 동작이 다르다.

## 원인

- `tui-kit.ts` 의 `promptField` · `readAtSpot` 은 `secret` 옵션으로 `*` 마스킹을 이미 지원한다.
- `cli.ts` 의 `ensureLogin` 이 비밀번호를 물을 때 `ask(rl, "비밀번호", "")` 로 불러 `secret` 이 꺼진 채였다.

## 해결

- 비밀번호 입력을 `ask(rl, "비밀번호", "", { secret: true })` 로 바꿨다.
- 입력 중에는 글자 수만큼 `*` 가 보이고, Backspace 로 지운다.
- Enter 를 누르면 같은 줄이 `입력완료` 로 바뀌어 비밀번호가 화면에 남지 않는다.
- TTY 가 아닌 환경(파이프 입력 등)은 `rl.question` 대체 경로를 타므로 마스킹되지 않는다.

## 적용 파일

- `lib/front/tui/cli.ts` — `ensureLogin`

## 검증
