# CASE-002: 미제출 과제가 지금 제출 기간 안에서만 보임

## 증상

- 메뉴 이름이 "현재 제출 기간 · 미제출" 이고, 기간이 지난 미제출은 목록에 없다.
- 전체 현황은 "해결과제" 로 지금 기간의 미제출만 센다.

## 원인

- `dueNow` 는 제출 기간이 열려 있고 아직 제출하지 않은 과제만 참이다.
- 미제출 메뉴와 전체 현황이 그 플래그를 그대로 세고 있었다.

## 해결

- 미제출 과제는 기간과 관계없이 제출 파일이 없는 과제다. 상태 문구는 `미제출` 이다.
- "지금 할 것" 과 "지금 할 수 있는 과제" 만 `dueNow` 를 유지한다.
- 차시 미완료는 지금 학습 기간 안의 미학습·학습중(`needsWatch`)만 센다.

## 적용 파일

- `lib/back/filters.ts` — `dueNow`, `assignmentEffectivelyUnsubmitted`, `needsWatch`
- `lib/front/tui/cli.ts` — 미제출 메뉴, 전체 현황
