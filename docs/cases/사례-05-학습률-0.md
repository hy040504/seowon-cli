# CASE-005: 완료한 차시도 학습률이 0%

## 증상

- 학습률 조회가 "학습률을 읽지 못했습니다" 로 실패한다.
- 완료한 차시까지 전부 0% 로 나온다.

## 원인

- 학습 상세 요청에 AJAX 헤더가 없어 학교가 기대하는 응답이 오지 않았다.
- HTML 표에서 "진도율" 과 `%` 사이에 날짜·행 번호가 있으면 퍼센트를 못 읽고, 본문에 "학습시간" 만 있어도 0으로 처리했다.
- 이력이 여러 줄이면 맨 앞 행의 0% 만 집었다.

## 해결

- `viewLessonStudyDetail` 에 공통 AJAX 헤더와 강의실 Referer 를 붙인다. 시청 기록은 보내지 않는다.
- 진도율 칸을 모두 읽어 가장 높은 값을 학습률로 쓴다.
- 학습 이력이 없다는 문구일 때만 0이다. 로그인 화면은 실패로 둔다.
- 실패 문구는 "학습률 응답을 해석하지 못했습니다."

## 적용 파일

- `lib/back/services/ecampus/elearning.ts` — `fetchProgress`
- `lib/back/filters.ts` — `findProgressPercent`
