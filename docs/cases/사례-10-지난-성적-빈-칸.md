# CASE-010: 지난 성적에서 과목만 나오고 성적 칸이 비음

## 증상

- 학기 과목 이름(데이터구조, 알고리즘 등)은 나오는데 성적 열이 비어 있다.
- 헤더가 과목 / 성적 두 칸뿐이다.

## 원인

- 화면이 `grade`, `gpa` 를 읽었다.
- ERP 과목 행의 등급은 `cmpsjGradeGrdCd`, 평점은 `cmpsjGp` 이다.

## 해결

- 목록은 과목, 구분, 학점, 등급, 평점이다. 과목 이름 옆에 등급 문자를 붙인다.
- 파서는 등급 문자 후보를 더 읽고, 없으면 노란 안내를 낸다. 빈 칸으로 두지 않는다.
- A/P 는 초록, B 는 하늘, C 는 노랑, D/F 는 밝은 빨강이다.

## 적용 파일

- `lib/back/engine/erp/grades.ts` — `pickGradeLetter`
- `lib/front/tui/cli.ts` — `pageScore`
