# CASE-022: 공지 상세에 제목이 본문으로 표시됨

## 증상

공지 메뉴에서 상세 내용을 열면 본문에 공지 제목과 작성자·공유 메뉴 등 화면 텍스트가 섞이고, 실제 내용은 제대로 보이지 않는다.

## 원인

- 현재 e-campus는 본문을 `id="atclCtsText" class="content-field"` 요소에 담는다. 기존 파서는 `atclCn`, `view-cont`, `bbs-view`만 인식했다.
- 본문을 찾지 못하면 상세 화면 전체를 평문으로 변환해 제목과 메뉴까지 내용에 들어갔다.
- 정규식은 첫 번째 `</div>`에서 끝나므로 중첩 요소 뒤의 내용을 놓쳤다. 8자 미만의 본문도 무시했다.

## 해결

- Cheerio로 실제 본문 요소를 선택해 중첩된 요소를 포함한 전체 내용을 추출한다.
- 현재 본문 영역을 우선하고 구버전 본문 영역·내용 라벨도 지원한다.
- 짧거나 빈 본문은 그대로 반환한다. 본문 영역을 찾지 못하면 빈 문자열을 반환해 CLI의 `(본문 없음)` 안내를 사용한다.
- 제목·작성자·공유 메뉴·첨부 목록·댓글을 본문에서 제외한다.

## 적용 파일

- `lib/back/filters.ts`
- `tests/notices.test.ts`
- `package.json`

## 검증

- `npm test`: 현재·구버전 본문, 중첩 HTML, 짧은·빈 본문, 본문이 없는 화면, 스크립트·스타일 제거, 상세 서비스의 본문·첨부 조회 등 7개 회귀 테스트 통과.
- `npm run typecheck`, `npm run build` 통과.
- 실제 `.env` 계정으로 e-campus에 로그인해 공지 6건을 조회했다. 추출한 본문은 각 응답의 `#atclCtsText` 텍스트와 일치했다.
- 첨부가 있는 공지에서 첨부 1건도 정상 조회했다. 파일 다운로드나 제출은 수행하지 않았다.

같은 회귀 테스트는 프로젝트 루트에서 `npm test`로 다시 실행한다. 빌드된 CLI를 사용하는 경우 `npm run build` 후 CLI를 다시 실행한다.
