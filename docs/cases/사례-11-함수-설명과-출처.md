# CASE-011: 함수 전수 조사와 호출 로그에 설명과 파일이 없음

## 증상

- 조사 목록이 함수 이름만 나열된다.
- `fetchSnapshot` 로그를 봐도 service · engine 의 어느 파일인지 모른다.

## 원인

- 조사 카탈로그가 이름 배열이었다.
- `bindApi` 가 함수 이름과 인자만 찍고, 구현 파일은 적지 않았다.

## 해결

- 각 함수 아래에 하는 일을 적는다. `listAssignments(missing)` 처럼 같은 함수를 다시 부르면 그 호출이 고른 대상을 구분한다.
- `--list` 와 실행 중 OK/FAIL/SKIP 줄이 같은 설명을 쓴다.
- `submitAssignment` 와 `logout` 은 호출하지 않고, 하지 않는 이유를 남긴다.
- 호출 로그 아래에 `lib/back` 기준 service 파일과 engine 파일을 붙인다. 메모리만 만지는 로그아웃·현재 학생·캐시 비우기는 파일 줄이 없다.

## 적용 파일

- `lib/front/tui/cli.ts` — `SURVEY_FUNCTIONS`, `surveyAbout`
- `lib/front/tui/tui-kit.ts` — `CALL_SOURCES`
