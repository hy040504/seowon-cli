# CASE-006: 다 들은 차시 목록이 "선택한 목록이 없습니다"

## 증상

- 들을 차시가 없을 때 항상 "선택한 이러닝 목록이 없습니다." 가 나온다.
- 전부 수강한 경우와 기간이 닫힌 경우가 구분되지 않는다.

## 원인

- 빈 목록을 한 문장으로만 처리했다. 차시가 없는 이유(전부 수강, 기간 종료, 출결 미상)를 세지 않았다.

## 해결

- 전체 차시를 집계해 상황에 맞는 문장을 낸다. 전부 수강이면 "전부 수강하였습니다" 이고 초록으로 보여 준다.
- 출결이 비어 있으면 완료로 치지 않는다. 미학습·학습중만 아직 들을 차시다.

## 적용 파일

- `lib/back/filters.ts` — `lessonWatchFacts`, `watchListEmptyMessage`
- `lib/front/tui/cli.ts` — 들을 차시 빈 화면
