# CASE-015: 로그인 메뉴가 .env 학번·비밀번호로 들어오지 않음

## 증상

- 로그인 메뉴의 프로필 칸이 환경변수 로그인으로 쓰이지 않는다.
- 프로젝트 루트의 `.env` 를 읽지 않으면 `SEOWON_SID`, `SEOWON_PW` 가 비어 있다.

## 원인

- Node는 `.env` 를 자동으로 읽지 않는다.
- 그 메뉴 칸이 로그인 동작과 연결되어 있지 않았다.

## 해결

- 시작 시 루트 `.env` 를 읽는다. 이미 셸에 값이 있으면 덮지 않는다.
- 로그인 메뉴 2번은 `.env` 의 학번·비밀번호로 로그인한다. 값이 없으면 "값 없음" 이고 로그인하지 않는다.
- 비밀번호는 화면에 찍지 않는다. `.env` 는 저장소에 올리지 않는다.

## 적용 파일

- `lib/front/tui/cli.ts` — `loadDotEnv`, `pageLogin`
- `.env.example`
