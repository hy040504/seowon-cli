# 서원대 CLI 문제 기록

> **프로젝트**: `seowon-cli`  
> **런타임**: Node.js 20 이상, TypeScript, 터미널 메뉴. 웹 서버 없음  
> **사례 파일**: `docs/cases/사례-NN-….md`  
> **최종 갱신**: 2026-09-24

이 문서는 이 CLI를 학교 서버에 직접 붙이면서 화면에 드러난 문제와 고친 내용을 모아 둔 기록입니다. 웹 서버·로드밸런서·관제 문제는 `seowon-client-web` 의 `docs/` 에 있습니다.

각 사례는 **증상**, **원인**, **해결**, **적용 파일** 순서입니다.

## 다시 볼 때

이미 켜 둔 터미널은 이전 화면을 유지합니다. 고친 메뉴를 보려면 CLI를 다시 실행합니다.

```powershell
npm run api-cli
```

타입만 확인합니다.

```powershell
npm run typecheck
```

`.env`, `downloads/`, `data/`, `dist/` 는 저장소에 올리지 않습니다.
